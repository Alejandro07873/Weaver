## Weaver 1.0.0 for Windows

Pick the nodes you want from an FModel Animation Blueprint export and paste them into Unreal Editor. Combine nodes from several ABPs in one TXT, reuse a combination as a preset and assign curves for KawaiiPhysics. MuscleEx and KawaiiPhysics require their editor plugins in the destination project.

**To get started:** download **Weaver.exe**, add a JSON in **Files**, choose your nodes in **Inspector** and click **Generate batch TXT**. The Windows ZIP contains the same executable.

Windows x64 · English and Spanish · Tested with Unreal Engine 4.27.
